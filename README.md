# Copy Editors' Crusade – OpenStreetMap Documentation Overhaul

We are a team of technical writers overhauling part of the **OpenStreetMap (OSM) Wiki** documentation. Our goal is to make it clear, task-based, and beginner-friendly.

## About the project

[OpenStreetMap](https://www.openstreetmap.org) is a free, community-built map of the world. Its beginner documentation lives on the [OSM Wiki](https://wiki.openstreetmap.org/wiki/Main_Page).

We:

1. Audited the existing beginner documentation.
2. Defined a content strategy for a new structure and audience.
3. Rewrote the content as separate **concept**, **task**, and **reference** topics, using our instructor's templates.
4. Peer-reviewed every topic within the team.
5. Improved the documentation for selected **OSM API** endpoints in Swagger.

## Target audience

Beginners who are new to OpenStreetMap and want to browse the map, understand OSM data, and start contributing.

## How we work

1. Each topic has one **issue** on the Project board.
2. The writer assigns themselves and moves the card from **Todo** to **In progress**.
3. The writer audits the original OSM page and writes the new topic in the **Wiki**, using the instructor's template.
4. The writer links the Wiki page in the issue and moves the card to **In review**.
5. A teammate reviews the topic and leaves comments on the issue.
6. The writer fixes the page and moves the card to **Done**.

## Templates

All topics follow the instructor's templates:
[Jordan Stanchev – Instructor's Example](https://github.com/JordanStanchev/Getting-Started-as-User-Assistance-Developer/wiki/Jordan-Stanchev---Instructor's-Example#templates)

| Topic type | Answers the question | Sections |
|---|---|---|
| Concept | What is this? | Summary, Detailed Overview, Example |
| Task | How do I do this? | Summary, Prerequisites, Steps, Result, Example |
| Reference | What are the facts? | Summary, then a reference heading (usually a table) |
