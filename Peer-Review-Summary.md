# Peer Review Summary

This page collects the evidence of our team's peer review. Every topic was reviewed by a different team member. The detailed review comments are on each topic's **issue** on the Project board.

## Review process

1. The writer finishes the Wiki page, links it in the issue, and moves the card to **In review**.
2. The writer @mentions the reviewer in a comment.
3. The reviewer reads the Wiki page, tests the steps, and comments on the issue using the checklist below.
4. The writer fixes the page, replies on the issue, and moves the card to **Done**.

## Review checklist

Reviewers used this checklist in their comments on the issue:

```
## Review
- [ ] Follows the instructor's template (correct headings, in order)
- [ ] Correct topic type (concept / task / reference not mixed)
- [ ] Steps tested on openstreetmap.org and they work
- [ ] Clear for a beginner; OSM terms explained
- [ ] Spelling and grammar
- [ ] At least one useful image, with a description
- [ ] Links work; related topics are linked
- [ ] Page title matches the issue title and the sidebar
Comments:
```
