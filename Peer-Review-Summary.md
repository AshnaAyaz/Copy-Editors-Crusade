
# Peer Review Summary

This page collects the evidence of our team's peer review. All 25 Wiki topics have been reviewed by another team member. Detailed review comments and follow-up corrections are recorded in each topic's GitHub Issue on the Project board.

## Review process

1. The writer finishes the Wiki page, links it in the issue, and moves the card to **In review**.
2. The writer @mentions the reviewer in a comment.
3. The reviewer reads the Wiki page, checks technical accuracy and usability, tests procedural steps where applicable, and provides feedback in the issue.
4. The writer incorporates the necessary corrections, replies on the issue, and moves the card to **Done**.

## Review checklist

The following checklist guided the team's peer reviews. Reviewers focused on the criteria relevant to each topic.

```text
## Review
- [ ] Follows the instructor's template (correct headings, in order)
- [ ] Correct topic type (Concept / Task / Reference)
- [ ] Procedural steps are accurate and tested where applicable
- [ ] Clear for the intended audience; OSM terms explained
- [ ] Spelling and grammar checked
- [ ] Useful visuals include descriptive alt text and captions, where applicable
- [ ] Links work; related topics are linked where helpful
- [ ] Page title matches the issue title and sidebar

Comments:
```
